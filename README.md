# 量潮创意工作

## 概述

创意工作——用 AI 做内容的作坊：方法（`docs/` 教程与手册）、半成品（`data/profile/` 生成素材）、未成形的项目（`examples/`）。单独拿出来是因为这里需要**高频迭代、记录中间过程**——内容反复改、每步中间态留痕；小说原文在 fiction（写作地，人维护，不动），立项后的成片生产在 drama。东西一旦立项成剧、奔着成片去，整套迁 drama；成片与上架归 drama，发布运营归 qtcloud-media，文件存储归 qtstore。

## 目录

- `data/context/` — 待归位记忆（quanttide-context-of-creative-work）
- `data/journal/` — 日志（quanttide-journal-of-creative-work）
- `data/library/` — 参考（quanttide-library-of-creative-work）
- `data/profile/` — 档案，按租户分目录（quanttide-profile-of-creative-work）
- `assets/fictions/founder/` — 小说原文（quanttide-fiction-of-founder），剧本改写的原始素材
- `apps/` — 应用：qtcloud-create（工作台，含 src/studio 界面）
- `docs/gallery/` — 案例集：工具与创意配合的判例（元方法）
- `docs/handbook/` — 手册：素材获取与内容制作
- `docs/essay/` — 随笔：AI 生图逼近脑中那一帧
- `docs/tutorial/` — 教程：创意工作入门、AI 原生创意工作
